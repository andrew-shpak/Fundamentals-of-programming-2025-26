# Лабораторна робота 19 — Класи, конструктори та деструктори

10 задач середньої складності з попереднього обговорення: копіювання, делегування конструкторів, складені об’єкти, статичні поля та порядок знищення. Теорія: [практикум із класів і конструкторів](../practice-classes-constructors/Readme.md).

Кожну задачу виконуйте як окрему консольну програму **C++20**. Поля класів мають бути приватними, початкові значення задавайте у списках ініціалізації. Методи, які лише читають дані, позначайте `const`. Вважайте, що ввід відповідає наведеним обмеженням. Повідомлення конструкторів і деструкторів виводьте лише там, де цього вимагає умова.

## Завдання 1 — Копія відрізка

[Розв’язок](src/task01_segment.cpp) · [Пояснення](Solutions.md)

Створіть клас `Segment`, який зберігає дві цілі координати на числовій прямій.

Конструктор `Segment(int a, int b)` повинен записати меншу координату як початок, більшу — як кінець. Реалізуйте конструктор копіювання, метод `Shift(int delta)` для переміщення обох кінців і метод обчислення довжини.

Введіть `a b delta`, кожне число від −1000 до 1000. Створіть відрізок та його копію. Перемістіть лише копію.

Виведіть оригінал, потім копію. Для кожного об’єкта надрукуйте початок, кінець і довжину через пробіл.

Ввід:
```text
12 4 -3
```

Очікуваний вивід:
```text
4 12 8
1 9 8
```

## Завдання 2 — Таймер із нормалізацією часу

[Розв’язок](src/task02_timer.cpp) · [Пояснення](Solutions.md)

Створіть клас `Timer`, який зберігає загальну кількість секунд.

Реалізуйте:

- `Timer(int hours, int minutes, int seconds)` — переводить усі аргументи в секунди;
- `Timer()` — делегує попередньому конструктору, задаючи одну хвилину;
- конструктор копіювання;
- `Tick(int elapsed)` — зменшує залишок часу, але не нижче нуля;
- `Print()` — виводить час у форматі `HH:MM:SS`.

Введіть години від 0 до 23, хвилини від 0 до 180, секунди від 0 до 120 та кількість минулих секунд від 0 до 10000.

Створіть стандартний таймер, таймер із введених даних і копію другого. Зменште час лише в копії. Виведіть три таймери в порядку створення, кожен з нового рядка.

Ввід:
```text
0 125 90 95
```

Очікуваний вивід:
```text
00:01:00
02:06:30
02:04:55
```

## Завдання 3 — Покупки з копією гаманця

[Розв’язок](src/task03_wallet.cpp) · [Пояснення](Solutions.md)

Створіть клас `Wallet` із цілим балансом, конструктором із параметром і конструктором копіювання.

Метод `bool Spend(int amount)` списує гроші, якщо їх достатньо, та повертає `true`. Інакше він повертає `false`, зберігаючи баланс.

Введіть початковий баланс від 0 до 10000, кількість покупок `n` від 1 до 20 і вартості `n` покупок від 1 до 10000.

Створіть гаманець та його копію. Усі покупки виконуйте копією. Для кожної спроби виведіть `OK` або `REJECTED`. В останньому рядку надрукуйте баланси оригіналу й копії.

Ввід:
```text
100 4
30 90 20 70
```

Очікуваний вивід:
```text
OK
REJECTED
OK
REJECTED
100 50
```

## Завдання 5 — Посилка зі складеним об’єктом

[Розв’язок](src/task05_parcel.cpp) · [Пояснення](Solutions.md)

Створіть клас `Dimensions`, який зберігає довжину, ширину й висоту коробки в сантиметрах. Додайте метод обчислення об’єму та метод зміни висоти.

Створіть клас `Parcel`, який містить об’єкт `Dimensions` і вагу в грамах. Конструктор копіювання `Parcel` повинен ініціалізувати розміри з відповідного об’єкта оригіналу.

Створіть посилку та її копію. Змініть висоту лише в копії. Для оригіналу й копії виведіть об’єм та вартість доставки, кожну пару з нового рядка.


## Завдання 7 — Об’єкт як параметр функції

[Розв’язок](src/task07_result.cpp) · [Пояснення](Solutions.md)

Створіть клас `Result` із балом від 0 до 100. Конструктор копіювання повинен друкувати `COPY <бал>`.

Метод `Add(int bonus)` додає бонус, обмежуючи результат значенням 100.

Реалізуйте дві функції:

- `Improve(Result result, int bonus)` — змінює отриманий об’єкт і друкує `LOCAL <бал>`;
- `Show(const Result& result)` — друкує `ORIGINAL <бал>`.

Введіть початковий бал і бонус, обидва від 0 до 100. Створіть константний об’єкт `Result`. Спочатку передайте його в `Improve`, потім у `Show`.

Ввід:
```text
85 30
```

Очікуваний вивід:
```text
COPY 85
LOCAL 100
ORIGINAL 85
```

Введіть дві назви модулів. У вкладеному блоці створіть робота та надрукуйте `WORK`. Після виходу з блоку надрукуйте `END`.


## Завдання 10 — Масив об’єктів і локальна копія

[Розв’язок](src/task10_record.cpp) · [Пояснення](Solutions.md)

Створіть клас `Record` із текстовою міткою.

- Конструктор із параметром друкує `NEW <мітка>`.
- Конструктор за замовчуванням делегує йому з міткою `empty`.
- Конструктор копіювання друкує `COPY <мітка>`.
- Деструктор друкує `DELETE <поточна мітка>`.
- Метод `Rename()` змінює мітку без повідомлень.

Введіть три слова: дві початкові мітки й нову мітку.

У блоці створіть звичайний масив із трьох об’єктів: перші два ініціалізуйте введеними мітками, третій — конструктором за замовчуванням. У вкладеному блоці створіть копію першого елемента, перейменуйте її третім словом і надрукуйте `INNER`.

Після знищення копії надрукуйте `ARRAY`. Після виходу з блоку з масивом надрукуйте `END`.

Ввід:
```text
Alpha Beta Gamma
```

Очікуваний вивід:
```text
NEW Alpha
NEW Beta
NEW empty
COPY Alpha
INNER
DELETE Gamma
ARRAY
DELETE empty
DELETE Beta
DELETE Alpha
END
```

## Запуск і перевірка

Кожен файл у `src/` — окрема повна програма. З кореня репозиторію:

```sh
c++ -std=c++20 -Wall -Wextra -Werror -pedantic lab-19/src/task01_segment.cpp -o /tmp/lab19-segment
printf '12 4 -3\n' | /tmp/lab19-segment
python3 lab-19/verify.py
```

Перевірка компілює всі 10 програм із AddressSanitizer/UndefinedBehaviorSanitizer і порівнює приклади та граничні випадки з `cases.json`. Бінарні файли створюються в тимчасовій директорії. Потрібні Python 3 та компілятор C++20; інший компілятор задається через `CXX`.
