# Лабораторна робота — Пам’ять і передавання даних у функції

Мета роботи — зрозуміти передавання за значенням, посиланням і вказівником, час життя даних та передавання володіння пам’яттю. Лабораторна містить **30 завдань від простого до складного**.

## Вимоги до виконання

- Кожне завдання — окрема програма C++20 у `lab-memory/src/`, наприклад `task01_by_value.cpp`. Реалізуйте вказану функцію; у `main()` вводьте дані, перевіряйте параметри, викликайте функцію та виводьте результат. Тут функції є обов’язковими: мета — дослідити різні способи передавання даних. Структури у завданнях 9, 10, 29 містять лише поля, без методів.
- Не використовуйте глобальних змінних. У функцію передавайте всі необхідні дані через параметри. Параметр `const` не змінюйте і не прибирайте `const` перетворенням типу.
- Якщо не вказано інше, вхідні числа й елементи належать діапазону від `-1000` до `1000`, довжина масиву `n` — від 0 до 100. Ці обмеження стосуються вводу; результати обчислень можуть виходити за діапазон `[-1000, 1000]`. Вважайте значення елементів коректними. Перевіряйте розміри, прапорці та індекси до звернення до пам’яті. При порушенні меж виведіть `Некоректні дані` та завершіть програму без інших результатів.
- Масив зазвичай вводиться як `n`, потім `n` елементів; при `n = 0` елементів немає. У завданнях 14–18 зберігайте дані у звичайному масиві місткості 100, без масивів змінної довжини. Функція отримує лише перші `n` елементів.
- Для пари «вказівник + довжина» за додатної довжини `nullptr` недопустимий: вказівник має вказувати щонайменше на зазначену кількість доступних елементів. При нульовій довжині дозволений `nullptr`; не розіменовуйте його і не виконуйте з ним арифметику вказівників. Перевірити реальну місткість довільного вказівника всередині функції неможливо — її гарантує сторона виклику. Окремі функції `ReadOrDefault`, `TryDouble` та `TrySwap` обробляють `nullptr` за власними умовами.
- У завданнях з `std::span` або `std::string_view` представлення не володіє даними. Власник має жити протягом усього використання представлення. Не повертайте посилання, вказівник або представлення на локальний об’єкт, знищений при виході з функції.
- Ручні `new[]` і `delete[]` використовуйте лише у завданнях 22–23. Кожне успішне виділення пам’яті звільняйте рівно один раз через `delete[]`. Після звільнення не звертайтеся до цієї пам’яті. Починаючи із завдання 24 використовуйте зазначені стандартні засоби володіння.
- Елементи результату-масиву виводьте через пробіл. Для порожнього результату-масиву виведіть `Порожній масив`. Порожній результат-рядок позначайте `Порожній рядок`. Логічні результати виводьте як `Так` або `Ні`. Не виводьте адреси пам’яті: вони змінюються між запусками.
- Рядки вводьте через `std::getline`, зберігаючи пробіли. У завданнях із рядками вхід має не більше 1000 друкованих ASCII-символів, без табуляцій. Якщо після числа читаєте повний рядок, спочатку пропустіть лише залишок поточного рядка, а не початкові пробіли наступного.
- Нижче наведено результати без запрошень до вводу. Копії всіх 30 прикладів є у [`samples/`](samples/).

## Частина 1 — Значення та посилання (1–10)

### Завдання 1 — Обчислення з параметром за значенням

Реалізуйте `int Square(int value)`, що повертає квадрат числа. Передайте введене `x` у функцію. Виведіть результат і початкове `x`, яке не змінюється.

Ввід:
```text
5
```
Вивід:
```text
Квадрат: 25
x: 5
```

### Завдання 2 — Зміна локальної копії

Реалізуйте `void AddTen(int value)`, яка додає 10 до свого параметра та виводить його значення у форматі `У функції: ...`. У `main()` після виклику виведіть початкове `x`. Це єдине завдання, де функція сама виводить діагностичний результат.

Ввід:
```text
7
```
Вивід:
```text
У функції: 17
Після виклику: 7
```

### Завдання 3 — Повернення нового значення

Реалізуйте `int Increment(int value)`, яка повертає число, збільшене на 1. У `main()` присвойте результат назад до `x` і виведіть його. Порівняйте спосіб зміни `x` із завданням 2.

Ввід:
```text
7
```
Вивід:
```text
8
```

Вивід:

Ввід:
```text

```
Вивід:
```text

```

### Завдання 6 — Читання рядка без копіювання

Реалізуйте `int CountSpaces(const std::string& text)`. Порахуйте звичайні пробіли, не копіюючи і не змінюючи рядок. Виведіть кількість. Порожній рядок дає 0.

Ввід:
```text

```
Вивід:
```text
3
```

### Завдання 7 — Зміна рядка через посилання

Реалізуйте `void AppendSuffix(std::string& text, const std::string& suffix)`. Введіть два рядки на окремих рядках і допишіть другий до першого. Сума їх довжин може перевищувати 1000. Аргументи у цьому завданні — два різні об’єкти; другий не змінюється. Виведіть змінений перший рядок.

Ввід:
```text
Hello
, world!
```
Вивід:
```text
Hello, world!
```

### Завдання 8 — Кілька вихідних параметрів

Реалізуйте `void MinMax(int a, int b, int& minimum, int& maximum)`. Перші два аргументи передаються за значенням, останні два отримують результати. У `main()` використайте різні змінні для результатів і виведіть мінімум та максимум.

Ввід:
```text

```
Вивід:
```text
Мінімум: -2
```

Ввід:
```text

```
Вивід:
```text
25
```

### Завдання 10 — Структура за змінюваним посиланням

```text

```
Вивід:
```text
2 9
```

## Частина 2 — Вказівники й передавання масивів (11–20)

### Завдання 11 — Вказівник, який може бути порожнім

Реалізуйте `int ReadOrDefault(const int* value, int fallback)`: поверніть значення за вказівником або `fallback` для `nullptr`. Введіть прапорець `present` (0 або 1), потім число лише при `present = 1`, потім `fallback`. У `main()` передайте адресу введеної змінної або `nullptr` згідно з прапорцем.

Ввід:
```text
0
7
```
Вивід:
```text
7
```

### Завдання 12 — Зміна значення через вказівник

Реалізуйте `bool TryDouble(int* value)`. Для `nullptr` поверніть `false`; інакше подвойте число за адресою та поверніть `true`. Формат вводу: прапорець `present` (0 або 1), потім значення лише при 1. Виведіть результат виклику, а при успіху — змінене число на наступному рядку.

Ввід:
```text
1
21
```
Вивід:
```text
Так
42
```

### Завдання 13 — Обмін за адресами

Реалізуйте `bool TrySwap(int* a, int* b)` без `std::swap`. Якщо хоча б один вказівник дорівнює `nullptr`, поверніть `false`, нічого не змінюючи; інакше обміняйте значення та поверніть `true`. У головному прикладі введіть два числа й передайте їх адреси. Виведіть логічний результат і обидва числа. Окремо перевірте `nullptr` та дві однакові адреси.

Ввід:
```text
4 9
```
Вивід:
```text
Так
9 4
```

### Завдання 14 — Масив як вказівник і довжина

Реалізуйте `int Sum(const int* data, int size)`. Поверніть суму перших `size` елементів, не змінюючи їх. Для `size = 0` поверніть 0. Не визначайте кількість елементів через `sizeof(data)`: параметр є вказівником, а не масивом.

Ввід:
```text
5
1 2 3 4 5
```
Вивід:
```text
15
```

### Завдання 15 — Зміна елементів масиву

Реалізуйте `void Scale(int* data, int size, int factor)`. Після масиву введіть множник `factor`. Змініть елементи у вихідному масиві та виведіть результат. За нульової довжини функція нічого не робить.

Ввід:
```text
4
1 -2 0 3
3
```
Вивід:
```text
3 -6 0 9
```

### Завдання 16 — Пошук без зміни даних

Реалізуйте `int FindFirst(const int* data, int size, int target)`. Після масиву введіть `target`. Поверніть індекс першого входження або `-1`, якщо елемент відсутній, зокрема для порожнього масиву.

Ввід:
```text
5
4 7 2 7 9
7
```
Вивід:
```text
1
```

### Завдання 17 — Копіювання з перевіркою місткості

Реалізуйте `bool Copy(const int* source, int size, int* destination, int capacity)`. Джерело й призначення — різні масиви, їх ділянки не перекриваються. Якщо `capacity < size`, поверніть `false` до будь-якого запису; інакше скопіюйте `size` елементів і поверніть `true`. Введіть вихідний масив і місткість від 0 до 100. У `main()` використайте другий масив місткості 100, але передайте зазначену логічну місткість. Виведіть логічний результат; при успіху — лише скопійовані елементи на наступному рядку. `size = 0` вважається успішною операцією.

Ввід:
```text
3
5 6 7
5
```
Вивід:
```text
Так
5 6 7
```

У прикладі `main()` використайте `int data[5]` і введіть рівно 5 чисел без попереднього `n`. Додатково перевірте виклик із масивом іншого сталого розміру.

Передайте двовимірний масив без копіювання та запишіть суми його рядків у вихідний масив. У прикладі використайте матрицю `2 × 3` та введіть лише 6 чисел, без розмірів. ## Частина 3 — Динамічна пам’ять, володіння та час життя (21–30)

### Завдання 21 — Прямокутник у плоскому буфері

Реалізуйте `int SumRectangle(const int* data, int rows, int cols, int r1, int c1, int r2, int c2)`. Матриця зберігається у справді одновимірному `int data[400]`, а елемент `[r][c]` має індекс `r * cols + c`. Не перетворюйте цей буфер на `int**`. Введіть `rows cols` (від 1 до 20), елементи по рядках, потім межі включного прямокутника, де `0 ≤ r1 ≤ r2 < rows` та `0 ≤ c1 ≤ c2 < cols`. Виведіть суму прямокутника.

Ввід:
```text
2 3
1 2 3
4 5 6
0 1 1 2
```
Вивід:
```text
16
```

### Завдання 22 — Створення динамічного масиву

Реалізуйте `int* CreateSequence(int size, int start, int step)`. Для додатного `size` виділіть масив через `new[]` і заповніть `data[i] = start + i * step`; для нуля поверніть `nullptr`. Введіть `size start step`, де `0 ≤ size ≤ 100`, а `start` і `step` — від `-100` до `100`. Володіння поверненим масивом отримує `main()`: він виводить елементи й звільняє пам’ять через `delete[]`.

Ввід:
```text

```
Вивід:
```text
2 5 8 11 14
```

### Завдання 23 — Заміна адреси через посилання на вказівник

Реалізуйте `void Resize(int*& data, int oldSize, int newSize)`. `data` належить викликачу та отриманий через `new[]` або дорівнює `nullptr` при `oldSize = 0`. Створіть новий масив, збережіть перші `min(oldSize, newSize)` елементів, решту заповніть нулями, потім звільніть старий буфер і оновіть вказівник. Для `newSize = 0` звільніть старий буфер і встановіть `nullptr`. Введіть початковий масив, потім новий розмір від 0 до 100. У `main()` після виклику оновіть логічний розмір, виведіть результат і звільніть новий буфер. Старі адреси та посилання на елементи більше не використовуйте.

Ввід:
```text
3
4 5 6
5
```
Вивід:
```text
4 5 6 0 0
```

У `main()` введіть розмір, отримайте власника та виведіть елементи. Не викликайте `delete[]`, `release()` і не створюйте другого власника з адреси `get()`.

### Завдання 29 — Кілька результатів у структурі

Оголосіть `struct Statistics { bool hasValue; int minimum; int maximum; long long sum; };`. Реалізуйте `Statistics Analyze(std::span<const int> values)`, що за один прохід повертає мінімум, максимум і суму. Для порожнього представлення поверніть `{false, 0, 0, 0}`. У `main()` виведіть `Немає даних` для порожнього вводу, інакше — три результати. Повернення структури за значенням не залишає посилань на локальні змінні.

Ввід:
```text
5
3 -2 7 0 4
```
Вивід:
```text
Мінімум: -2
Максимум: 7
Сума: 12
```

### Завдання 30 — Представлення на вході, власний рядок на виході

Реалізуйте `std::string CopyWord(std::string_view text, int index)`, яка повертає власну копію слова із заданим індексом. Слова — непорожні послідовності між звичайними пробілами; індекси починаються з 0. Введіть повний рядок, потім `index` від 0 до 1000. Якщо слова з таким індексом немає, поверніть порожній `std::string`. Розберіть вхід через індекси або `std::string_view`, не копіюючи весь текст; скопіюйте лише знайдене слово у результат. Функція не повинна повертати `std::string_view`: результат має залишатися дійсним після знищення вхідного рядка. У `main()` збережіть результат поза вкладеною областю, де живе вхідний рядок, і виведіть його після виходу з цієї області.

Ввід:
```text
  one   two three
1
```
Вивід:
```text
two
```

## Перевірка та здача

- Запустіть кожну програму на її прикладі та порівняйте результат із `samples/`. Додатково перевірте нуль, від’ємні числа, однакові значення, порожні масиви й рядки та найбільші допустимі розміри.
- Для посилань перевірте зміни оригіналу й незмінність `const`-аргументів. Для вказівників окремо перевірте дозволені `nullptr`, для масивів — нульову довжину. Не створюйте навмисно недійсних адрес і не розіменовуйте звільнену пам’ять.
- Для копіювання перевірте місткість, меншу, рівну та більшу за довжину. При невдачі призначення має залишитися незмінним. Для `TryMax` перевірте, що невдача не змінює вихідний параметр.
- Для зміни розміру перевірте збільшення, зменшення, однаковий розмір, `0 → n`, `n → 0` та `0 → 0`. Після кожного сценарію пам’ять має мати одного відповідального власника.
- Для представлень перевірте порожній діапазон та піддіапазон біля кінця буфера. У завданні 30 перевірте відсутнє слово, кілька пробілів і друк результату після знищення початкового рядка.
- Для завдань 22–30 за можливості запустіть перевірку AddressSanitizer та UndefinedBehaviorSanitizer. Відсутність повідомлень доповнює, але не замінює перевірку результатів і правил володіння.
- Здайте 30 окремих файлів `.cpp`. Для кожного коротко поясніть, які параметри копіюються, які дають доступ до оригіналу, хто володіє пам’яттю та скільки живуть передані дані.
