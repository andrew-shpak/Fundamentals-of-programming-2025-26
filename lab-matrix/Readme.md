# Лабораторна робота — Матриці: шаблони та масиви масивів

Мета роботи — навчитися працювати з прямокутними та квадратними матрицями й відокремлювати тип елементів від алгоритму. Лабораторна містить **50 завдань**: 30 завдань із шаблонною структурою `Matrix<T>` та 20 завдань із масивами масивів. У кожному блоці завдання розташовані від простого до складного.

## Вимоги до виконання

- Кожне завдання — окрема програма C++20 у `lab-matrix/src/`, наприклад `task01_print.cpp`.
- У завданнях 1–30 використовуйте наведену нижче шаблонну структуру `Matrix<T>` лише для зберігання даних. Не додавайте до неї методів, конструкторів або перевантажених операторів. Усі введення, перевірки, обчислення й виведення в усіх 50 завданнях розміщуйте в `int main()`, без додаткових функцій або лямбда-виразів.
- Для завдань 1–30 поза `main()` дозволені директиви `#include`, визначення `Matrix<T>` та псевдонім `Value`. Приклад структури не є розв'язанням завдань:

```cpp
template<typename T>
struct Matrix {
    int rows = 0;
    int cols = 0;
    T data[20][20]{};
};

using Value = int;
```

- У завданнях 1–30 створюйте матриці як `Matrix<Value>`. Перевірте кожну з цих програм з `Value = int` і з `Value = double`, змінюючи лише псевдонім типу. Алгоритм та оголошення проміжних значень мають враховувати `Value`; розміри, індекси й лічильники залишаються цілими. Не створюйте дві копії алгоритму для різних типів.
- У завданнях 31–50 використовуйте звичайні двовимірні масиви `int matrix[20][20]{}` та окремі змінні `rows`, `cols` для фактичних розмірів. Це масив із 20 рядків, кожен із яких є масивом із 20 чисел; доступ до елемента — `matrix[row][column]`. Не створюйте `Matrix<T>` або інших структур. Поза `main()` залишайте лише директиви `#include`.
- Для сум і добутків використовуйте накопичувачі, ініціалізовані нулем: типу `Value` у завданнях 1–30 і типу `int` у завданнях 31–50. Для середнього використовуйте `double`, щоб уникнути цілочисельного ділення. За наведених обмежень результати для `int` не виходять за межі 32-бітного знакового типу.
- Розміри кожної матриці: `1 ≤ rows, cols ≤ 20`. Елементи та скаляр завдання 11 лежать у межах від `-1000` до `1000`; для `double` дозволено дробові значення. Вважайте елементи та скаляр коректно введеними скінченними числами в цих межах.
- Перевіряйте розміри до введення елементів, а індекси й сумісність матриць — до виконання операції. При некоректних параметрах виведіть `Некоректні дані` та завершіть програму. Індекси починаються з 0, межі відрізків включні.
- За замовчуванням вводяться `rows cols`, далі `rows * cols` елементів по рядках, потім додаткові параметри. Для двох матриць введіть спочатку розміри й елементи першої, потім розміри й елементи другої. Для квадратної матриці також вводьте обидва розміри та перевіряйте їх рівність.
- Результат-матрицю виводьте по рядках, значення відокремлюйте пробілами, без розмірів перед результатом. Для `int` виводьте цілі значення. Для `double` числові значення елементів і результатів виводьте з двома знаками після крапки; індекси й лічильники — як цілі. Середнє завдань 3 і 33 завжди має два знаки після крапки.
- Для перевірок рівності у завданнях 10, 24, 25 з `double` використовуйте `std::abs(a - b) <= 1e-9`, а з `int` — точну рівність. Для максимумів, мінімумів та порядку використовуйте звичайні `<` і `>` без округлення. Знаки у завданні 5 визначайте прямим порівнянням із нулем.
- Використовуйте вкладені цикли, індекси, умови та звичайні допоміжні масиви. Не використовуйте `std::vector`, готові алгоритми, бібліотеки матриць або масиви змінної довжини на зразок `Value data[rows][cols]`.
- Нижче наведено приклади з цілими вхідними елементами без запрошень до вводу. Копії всіх 50 прикладів розміщено у [`samples/`](samples/).
