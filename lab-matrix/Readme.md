# Лабораторна робота — Узагальнені матриці без методів

Мета роботи — навчитися працювати з прямокутними та квадратними матрицями й відокремлювати тип елементів від алгоритму. Лабораторна містить **30 завдань від простого до складного**.

## Вимоги до виконання

- Кожне завдання — окрема програма C++20 у `lab-matrix/src/`, наприклад `task01_print.cpp`.
- Використовуйте наведену нижче шаблонну структуру `Matrix<T>` лише для зберігання даних. Не додавайте до неї методів, конструкторів або перевантажених операторів. Усі введення, перевірки, обчислення й виведення розміщуйте в `int main()`, без додаткових функцій або лямбда-виразів.
- Поза `main()` дозволені директиви `#include`, визначення `Matrix<T>` та псевдонім `Value`. Приклад структури не є розв'язанням завдань:

```cpp
template<typename T>
struct Matrix {
    int rows = 0;
    int cols = 0;
    T data[20][20]{};
};

using Value = int;
```

- Створюйте матриці як `Matrix<Value>`. Перевірте кожну програму з `Value = int` і з `Value = double`, змінюючи лише псевдонім типу. Алгоритм та оголошення проміжних значень мають враховувати `Value`; розміри, індекси й лічильники залишаються цілими. Не створюйте дві копії алгоритму для різних типів.
- Для сум і добутків використовуйте накопичувачі типу `Value`, ініціалізовані нулем. Для середнього використовуйте `double`, щоб уникнути цілочисельного ділення. За наведених обмежень результати для `int` не виходять за межі 32-бітного знакового типу.
- Розміри кожної матриці: `1 ≤ rows, cols ≤ 20`. Елементи та скаляр завдання 11 лежать у межах від `-1000` до `1000`; для `double` дозволено дробові значення. Вважайте елементи та скаляр коректно введеними скінченними числами в цих межах.
- Перевіряйте розміри до введення елементів, а індекси й сумісність матриць — до виконання операції. При некоректних параметрах виведіть `Некоректні дані` та завершіть програму. Індекси починаються з 0, межі відрізків включні.
- За замовчуванням вводяться `rows cols`, далі `rows * cols` елементів по рядках, потім додаткові параметри. Для двох матриць введіть спочатку розміри й елементи першої, потім розміри й елементи другої. Для квадратної матриці також вводьте обидва розміри та перевіряйте їх рівність.
- Результат-матрицю виводьте по рядках, значення відокремлюйте пробілами, без розмірів перед результатом. Для `int` виводьте цілі значення. Для `double` числові значення елементів і результатів виводьте з двома знаками після крапки; індекси й лічильники — як цілі. Середнє завдання 3 завжди має два знаки після крапки.
- Для перевірок рівності у завданнях 10, 24, 25 з `double` використовуйте `std::abs(a - b) <= 1e-9`, а з `int` — точну рівність. Для максимумів, мінімумів та порядку використовуйте звичайні `<` і `>` без округлення. Знаки у завданні 5 визначайте прямим порівнянням із нулем.
- Використовуйте вкладені цикли, індекси, умови та звичайні допоміжні масиви. Не використовуйте `std::vector`, готові алгоритми, бібліотеки матриць або масиви змінної довжини на зразок `Value data[rows][cols]`.
- Нижче наведено приклади для `Value = int` без запрошень до вводу. Копії всіх 30 прикладів розміщено у [`samples/`](samples/).

## Частина 1 — Введення, обхід і аналіз (1–10)

Введіть матрицю та виведіть її без змін, зберігаючи розташування всіх елементів.

Вивід:
```text

```

```text

```
Вивід:
```text
12
```

```text

```
Вивід:

Ввід:

Вивід:

## Перевірка та здача

- Перевірте кожне завдання на його прикладі та порівняйте результат із `samples/`. Повторіть запуск із `Value = double`, додавши дробові елементи; змінюйте лише псевдонім, а не алгоритм.
- Перевірте `1 × 1`, один рядок, один стовпець, прямокутну матрицю, нулі, лише від’ємні елементи, повторення та розмір `20 × 20`.
- Для пошуку перевірте відсутнє значення; для мінімумів, максимумів і найкращого рядка — однакові результати та правило вибору.
- Для обміну перевірте однакові індекси; для транспонування й повороту — різні кількості рядків і стовпців; для сідлових точок — відсутність і кілька відповідей.
- Перевірте відхилення нульових і завеликих розмірів, некоректних індексів, неквадратних матриць у завданнях 21–25 та несумісних розмірів у завданнях 12–14 і 28.
- Здайте 30 файлів `.cpp`. У кожному має бути структура `Matrix<T>` без методів та лише одна функція — `main()`.
