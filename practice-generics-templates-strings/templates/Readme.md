# Практикум — Шаблонні типи (10 завдань)

Мета — параметризувати структуру даних типами, місткістю й операціями. Це продовження [узагальнених алгоритмів](../generics/Readme.md): там змінювався тип аргументів функцій, тут змінюється сам тип контейнера.

## Спільні правила

- Кожне завдання — окрема програма C++20. Використовуйте звичайні масиви; готові контейнери не потрібні.
- Параметри `N`, `Rows`, `Cols` — додатні константи часу компіляції, а не розміри, введені з клавіатури. `static_assert` відхиляє недопустимий тип при компіляції.
- Для задач із `n` / кількістю команд допустимі значення 0–100. Якщо не вказано інше, усі числові дані — коректні цілі від -1000 до 1000; це також обмежує суми й квадрати безпечним діапазоном `int`.
- Невдале читання, неправильні розміри, індекси, прапорці або невідомі команди дають `Некоректні дані`. Переповнення / спорожнення контейнера є очікуваним результатом `Помилка`, після якого наступні команди виконуються.
- У задачах 4–5 при нулі команд виводу немає. Для порожнього результату-масиву в задачі 9 виведіть `Порожній масив`.
- Шаблонні контейнери тут розраховані на типи, що підтримують використані операції копіювання, присвоєння, порівняння та створення початкового значення. Це навчальні реалізації без керування сирою динамічною пам’яттю.
- Додатково перевірте типи: `Box<std::string>`, `Pair<int, double>`, `FixedArray<double, 2>`, `Stack<std::string, 2>`, `Queue<double, 2>`, `Statistics<double>`, `Dictionary<int, std::string, 2>`, `Matrix<double, 1, 3>`, іншу операцію для `Transformer` та `Formatter<std::string>`. Змінюйте лише демонстраційний `main()`; реалізація шаблону залишається та сама.

## Завдання

### Завдання 1 — Контейнер одного значення

Створіть `Box<T>` із приватним значенням, конструктором, `const T& Get() const` та `void Set(const T&)`. Введіть два цілі числа: першим ініціалізуйте `Box<int>`, другим змініть його. Виведіть стан до та після зміни.

[Повна реалізація](src/task01_box.cpp) · [Консольний приклад](samples/task01_box.txt)

Ввід:
```text
7 12
```
Вивід:
```text
7
12
```

### Завдання 2 — Пара різних типів

Створіть `Pair<First, Second>` з відкритими полями `first` і `second`. Введіть ім’я одним словом і цілий бал, збережіть їх у `Pair<std::string, int>` та виведіть як `ім’я: бал`.

[Повна реалізація](src/task02_pair.cpp) · [Консольний приклад](samples/task02_pair.txt)

Ввід:
```text
Anna 95
```
Вивід:
```text
Anna: 95
```

### Завдання 3 — Масив із розміром у типі

Створіть `FixedArray<T, N>` із `static_assert(N > 0)`, приватним масивом і перевантаженнями `At(int)` для читання та зміни. Некоректний індекс має кидати `std::out_of_range`. Для `FixedArray<int, 5>` введіть п’ять чисел, індекс і нове значення; змініть елемент та виведіть весь масив.

[Повна реалізація](src/task03_fixed_array.cpp) · [Консольний приклад](samples/task03_fixed_array.txt)

Ввід:
```text
1 2 3 4 5
2 9
```
Вивід:
```text
1 2 9 4 5
```

### Завдання 4 — Стек фіксованої місткості

Створіть `Stack<T, N = 3>` з методами `bool Push(const T&)`, `bool Pop(T&)`, `int Size() const`. `Pop` повертає останній доданий елемент (LIFO). Невдала операція не змінює стан або вихідний параметр. Використайте `Stack<int>`. Ввід: кількість команд `0..100`, далі `push x`, `pop` або `size`. Усі команди зчитайте й перевірте до виконання. Для `push` виводьте `OK` / `Помилка`, для `pop` — значення / `Помилка`, для `size` — поточний розмір. Невідомі або неповні команди дають `Некоректні дані`.

[Повна реалізація](src/task04_stack.cpp) · [Консольний приклад](samples/task04_stack.txt)

Ввід:
```text
7
push 10
push 20
size
pop
pop
pop
size
```
Вивід:
```text
OK
OK
2
20
10
Помилка
0
```

### Завдання 5 — Кільцева черга

Створіть `Queue<T, N = 3>` з методами `bool Push(const T&)`, `bool Pop(T&)`, `int Size() const`. `Pop` повертає найраніше доданий елемент (FIFO). Реалізуйте кільцевий буфер: звільнені позиції використовуються знову без зсування. Невдала операція не змінює стан або вихідний параметр. Використайте `Queue<int>`. Ввід: кількість команд `0..100`, далі `push x`, `pop` або `size`. Усі команди зчитайте й перевірте до виконання. Для `push` виводьте `OK` / `Помилка`, для `pop` — значення / `Помилка`, для `size` — поточний розмір. Невідомі або неповні команди дають `Некоректні дані`.

[Повна реалізація](src/task05_queue.cpp) · [Консольний приклад](samples/task05_queue.txt)

Ввід:
```text
7
push 10
push 20
size
pop
pop
pop
size
```
Вивід:
```text
OK
OK
2
10
20
Помилка
0
```

### Завдання 6 — Статистика потоку значень

Створіть `Statistics<T>` з методами `Add(const T&)`, `Count()`, `Sum()` та `bool MinMax(T&, T&) const`. Не зберігайте весь потік: оновлюйте кількість, суму, мінімум і максимум при додаванні. Для порожнього потоку `MinMax` повертає `false`, не змінюючи аргументи. Введіть `n` і `n` цілих значень; виведіть кількість, суму та межі або `Немає значень`.

[Повна реалізація](src/task06_statistics.cpp) · [Консольний приклад](samples/task06_statistics.txt)

Ввід:
```text
4
-3 8 2 1
```
Вивід:
```text
Кількість: 4
Сума: 8
-3 8
```

### Завдання 7 — Словник із двома параметрами типу

Створіть `Dictionary<Key, Value, N>` з методами `bool Set(const Key&, const Value&)` і `bool TryGet(const Key&, Value&) const`. Оновлення наявного ключа дозволене навіть у повному словнику. Новий ключ при заповненій місткості повертає `false`. Відсутній ключ не змінює вихідний параметр. Для `Dictionary<std::string, int, 3>` введіть `n` пар `ключ значення` (`0..100`), потім ключ пошуку. Усі ключі — окремі слова. Для кожної пари виведіть `OK` / `Помилка`, потім знайдене значення / `Не знайдено`. Спочатку зчитайте всі дані.

[Повна реалізація](src/task07_dictionary.cpp) · [Консольний приклад](samples/task07_dictionary.txt)

Ввід:
```text
4
apple 3
pear 5
apple 8
plum 2
apple
```
Вивід:
```text
OK
OK
OK
OK
8
```

Вивід:
```text

2 5

```

### Завдання 9 — Тип операції як параметр шаблону

Створіть `Transformer<T, Operation>` зі статичним методом `Apply(T* data, int size, const Operation& operation)`. Метод замінює кожен елемент на `operation(element)`. Реалізуйте функціональний об’єкт `Square` з `int operator()(int) const`. Для масиву цілих чисел виконайте піднесення до квадрата. `n` — від 0 до 100, елементи — від -1000 до 1000.

[Повна реалізація](src/task09_transform.cpp) · [Консольний приклад](samples/task09_transform.txt)

Ввід:
```text
4
-3 0 2 5
```
Вивід:
```text
9 0 4 25
```

### Завдання 10 — Повна спеціалізація шаблону

Створіть `Formatter<T>` зі статичним методом `Print(const T&)`, який виводить значення звичайним способом. Повністю спеціалізуйте `Formatter<bool>`, щоб він виводив `Так` або `Ні`. Введіть ціле число та прапорець 0/1; виведіть число через загальний шаблон, потім прапорець через спеціалізацію.

[Повна реалізація](src/task10_formatter.cpp) · [Консольний приклад](samples/task10_formatter.txt)

Ввід:
```text
42 1
```
Вивід:
```text
42
Так
```
