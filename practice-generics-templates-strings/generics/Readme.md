# Практикум — Узагальнені алгоритми (10 завдань)

Мета — записати алгоритм один раз для різних типів елементів. У C++ це реалізовано шаблонами функцій `template<typename T>`. Кожна програма самодостатня; допоміжні `ReadArray` і `PrintArray` у файлах потрібні для консольного прикладу.

## Спільні правила

- C++20, звичайні масиви, цикли та умови; без готових алгоритмів і контейнерів STL.
- `using Value = int;` визначає тип вхідних значень. Повторіть запуск з `using Value = double;` та дробовими даними, не змінюючи алгоритм. Звичайний формат виводу потоку зберігається для обох типів (наприклад, `2.5`, а не обов’язково `2.50`).
- Для задач 2–9 введіть `n`, потім `n` елементів; для 4–5 — також цільове значення. Для 10 введіть два такі масиви послідовно. `0 ≤ n ≤ 100`; завдання 2 вимагає `n ≥ 1`.
- Значення та ціль — скінченні числа від -1000 до 1000. Тип числових токенів має відповідати `Value`. Некоректний розмір, значення за межами або невдале читання дають `Некоректні дані`.
- Індекси з 0; порожній результат-масив — `Порожній масив`. Суми з цими межами не переповнюють `int`.
- Для `double` у пошуку та видаленні повторень використовується точна рівність введених значень. Наближене порівняння результатів обчислень є окремою темою.
- Шаблон не робить будь-який тип допустимим: обмін потребує копіювання та присвоєння, пошук — `==`, порядок — `<`, сума — нульового значення та `+=`. Консольні приклади перевіряються з `int` і `double`.
- Функції з параметрами `data, size` отримують коректну довжину та достатню місткість від `main()`. `FindMinMax` потребує непорожнього масиву; `Unique` та `MergeSorted` — незалежного вихідного буфера. Перевірки вводу виконує `main()` / `ReadArray`.

## Завдання

### Завдання 1 — Обмін двох значень

Реалізуйте `Swap(T& a, T& b)` через тимчасову змінну, без `std::swap`. Введіть два значення й виведіть їх після обміну. Виклик з одним об’єктом в обох аргументах також має бути коректним.

[Повна реалізація](src/task01_swap.cpp) · [Консольний приклад](samples/task01_swap.txt)

Ввід:
```text
3 8
```
Вивід:
```text
8 3
```

### Завдання 2 — Мінімум і максимум

Реалізуйте `FindMinMax(const T* data, int size, T& minimum, T& maximum)`. Масив має бути непорожнім. Початкові мінімум і максимум візьміть із першого елемента; виведіть обидва значення через пробіл.

[Повна реалізація](src/task02_min_max.cpp) · [Консольний приклад](samples/task02_min_max.txt)

Ввід:
```text
5
4 -2 9 -2 0
```
Вивід:
```text
-2 9
```

### Завдання 3 — Сума елементів

Реалізуйте `T Sum(const T* data, int size)`. Накопичувач створіть як `T{}`. Для порожнього масиву поверніть нульове значення. Введіть масив і виведіть суму.

[Повна реалізація](src/task03_sum.cpp) · [Консольний приклад](samples/task03_sum.txt)

Ввід:
```text
5
1 -2 3 0 5
```
Вивід:
```text
7
```

### Завдання 4 — Перше входження

Реалізуйте `int FindFirst(const T* data, int size, const T& target)`. Після масиву введіть шукане значення. Поверніть індекс першого входження або `-1`, зокрема для порожнього масиву.

[Повна реалізація](src/task04_find_first.cpp) · [Консольний приклад](samples/task04_find_first.txt)

Ввід:
```text
5
4 7 4 9 4
4
```
Вивід:
```text
0
```

### Завдання 5 — Кількість входжень

Реалізуйте `int CountEqual(const T* data, int size, const T& target)`. Після масиву введіть значення для підрахунку. Поверніть кількість точних збігів; для порожнього масиву — 0.

[Повна реалізація](src/task05_count.cpp) · [Консольний приклад](samples/task05_count.txt)

Ввід:
```text
5
4 7 4 9 4
4
```
Вивід:
```text
3
```

### Завдання 6 — Розворот на місці

Реалізуйте `Reverse(T* data, int size)`: обмінюйте симетричні елементи до середини масиву. Другий масив не створюйте. Порожній масив і один елемент залишаються без змін.

[Повна реалізація](src/task06_reverse.cpp) · [Консольний приклад](samples/task06_reverse.txt)

Ввід:
```text
5
1 2 3 4 5
```
Вивід:
```text
5 4 3 2 1
```

### Завдання 7 — Перевірка впорядкованості

Реалізуйте `bool IsSorted(const T* data, int size)`. Перевірте неспадний порядок; рівні сусідні елементи дозволені. Порожній масив і один елемент вважайте впорядкованими. Виведіть `Так` або `Ні`.

[Повна реалізація](src/task07_is_sorted.cpp) · [Консольний приклад](samples/task07_is_sorted.txt)

Ввід:
```text
5
-2 0 0 3 9
```
Вивід:
```text
Так
```

### Завдання 8 — Сортування вставками

Реалізуйте `InsertionSort(T* data, int size)` за неспаданням. Вставляйте поточне значення у вже впорядкований префікс, зсуваючи лише строго більші елементи. Це зберігає взаємний порядок рівних елементів.

[Повна реалізація](src/task08_insertion_sort.cpp) · [Консольний приклад](samples/task08_insertion_sort.txt)

```text

```
Вивід:
```text
-5 -1 0 2 3 3
```

### Завдання 9 — Унікальні значення зі збереженням порядку

Реалізуйте `int Unique(const T* data, int size, T* result)`. Запишіть у незалежний вихідний масив лише перші входження значень і поверніть його розмір. Вхід не змінюйте; не сортуйте його. Місткість результату — щонайменше `size`.

[Повна реалізація](src/task09_unique.cpp) · [Консольний приклад](samples/task09_unique.txt)

Ввід:
```text
6
3 1 3 2 1 4
```
Вивід:
```text
3 1 2 4
```

### Завдання 10 — Злиття впорядкованих масивів

Реалізуйте `int MergeSorted(const T* first, int n, const T* second, int m, T* result)`. Введіть два масиви у неспадному порядку, перевірте цей порядок і злийте їх за O(n + m). Повторення збережіть; при рівності спочатку беріть елемент першого масиву. Місткість результату — 200.

[Повна реалізація](src/task10_merge.cpp) · [Консольний приклад](samples/task10_merge.txt)

Ввід:
```text
3
1 3 5
4
2 3 4 6
```
Вивід:
```text
1 2 3 3 4 5 6
```
